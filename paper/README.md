# paper

Paper A: `main.tex` (SoCC format: `acmart` sigconf, review, anonymous), `sections/`, `tables/` (generated), `numbers.tex` (generated by `make numbers`), `refs.bib`. Paper B lives in `paper-b/` from Week 55. Numbers only from macros; figures only from `results/` (`make figures`).

## LaTeX (BasicTeX, chosen 5 Oct 2026)

```bash
brew install --cask basictex
```
Open a new terminal, then:
```bash
sudo tlmgr update --self
```
```bash
sudo tlmgr install latexmk acmart totpages environ trimspaces ncctools comment hyperxmp ifmtarg xstring libertine inconsolata newtx fontaxes kastrup preprint draftwatermark zref xcolor booktabs caption cmap etoolbox iftex pbalance xspace
```
Then `make paper` from the repository root. If latexmk reports a missing `.sty`, install the package of that name with `sudo tlmgr install <name>`.
